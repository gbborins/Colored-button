# 🎨 Colored Button

Projeto de interface web interativa focado na manipulação dinâmica de estilos e lógica de interação utilizando **HTML, CSS e JavaScript**.

## 📌 Descrição

O **Colored Button** é uma aplicação web que permite ao usuário interagir com botões que alteram dinamicamente suas cores e comportamentos. Além disso, o projeto inclui um **modo puzzle**, no qual o usuário precisa identificar ou organizar padrões de cores, tornando a experiência mais lógica e interativa.

O projeto demonstra conceitos fundamentais de **manipulação do DOM**, **eventos em JavaScript** e **interatividade em tempo real**.

## 🚀 Funcionalidades

- Alteração dinâmica de cores de botões
- Interação em tempo real com o usuário
- Manipulação de eventos (click, hover, etc.)
- Atualização de estilos via JavaScript
- 🧩 **Modo puzzle com lógica baseada em cores**
- Feedback visual baseado nas ações do usuário

## 🛠️ Tecnologias utilizadas

- HTML5
- CSS3
- JavaScript

## 🧩 Sobre o Puzzle

O modo puzzle adiciona uma camada lógica ao projeto, exigindo que o usuário:

- Reconheça padrões de cores
- Interaja corretamente com os botões
- Resolva um desafio baseado em tentativa e lógica

Essa funcionalidade demonstra aplicação prática de:

- Estruturas condicionais
- Controle de estados
- Feedback visual interativo
